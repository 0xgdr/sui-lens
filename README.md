# Sui Lens

Sui Lens is a learning-first Sui transaction explorer. It teaches a JavaScript developer how to read Sui objects, PTBs, effects, gas, and Move calls from real chain evidence.

This is the production successor to the completed POC in `../sui-lens`. The POC remains the working record of the original transaction microscope, Backpack Journey, and teaching experiments. This repository owns the production Astro architecture, learning tracks, content model, and live read-only Lens.

## Current foundation

- the six-stop Backpack Journey as the primary story-led learning route;
- three Markdown-driven reference tracks with nine lessons;
- the original Backpack, map, compass, pass, checkpoint, tag, and receipt icons restored as teaching assets;
- static track and lesson routes generated by Astro content collections;
- prediction, JavaScript bridge, evidence, and local completion components;
- a five-question Transaction Lens for real mainnet transaction digests;
- evidence-aware Move signature and BCS decoding with raw values kept nearby;
- tested boundaries between read-only acquisition, normalization, explanation, and presentation;
- responsive browser checks for every learning route and the main interactive workbenches;
- a project-local `learn-sui-by-building` agent skill.

See [docs/architecture.md](./docs/architecture.md) for the route map, content schema, design system, and Lens architecture.

## Development

```sh
bun install
bun astro dev --background
```

Manage the background server with:

```sh
bun astro dev status
bun astro dev logs
bun astro dev stop
```

Build the static site with:

```sh
bun run build
```

Install the browser used by the quality checks once:

```sh
bunx playwright install chromium
```

Run unit tests, the production build, and responsive browser checks together:

```sh
bun run check
```

GitHub Actions runs the same quality gate for pull requests and changes to `main`.
